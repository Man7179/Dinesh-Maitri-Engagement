# Maitri & Dinesh — Royal Engagement Invitation

Premium responsive single-page invitation. On desktop, it is displayed inside a dimensional iPhone-inspired mockup with subtle pointer-driven 3D tilt. On mobile, the invitation fills the screen for a natural phone experience. The screen includes an interactive raised gold seal, opening doors, cinematic light leaks, animated particles, scroll-triggered fade/blur, glossy burgundy-and-gold glass panels, the supplied couple photograph, countdown, venue directions and tap-to-call contacts.

## Quick start
Open `index.html` in your browser. No build tools or dependencies are needed. Internet access is needed for Google Fonts and external Google Maps / WhatsApp links.

## Customize
- `config.js`: date/time, venue, family names, contact numbers, WhatsApp number. Date uses Indian time (`+05:30`).
- `index.html`: invitation wording, sections and couple names.
- `assets/maitri-dinesh.jpg`: supplied photograph. Replace this file with another image if required.
- Optional licensed background music: add your own `assets/music.mp3`. The website does not include a copyrighted audio track; the music button will prompt for a file if missing.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `config.js`, `README.md`, and the `assets` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
4. Wait for GitHub Pages to publish the link.

## Accessibility / motion
The seal is a keyboard-accessible button. `prefers-reduced-motion` is respected. Phone 3D tilt only activates on desktop pointer devices. A real iPhone hardware render is not embedded: this is a CSS-based iPhone-inspired 3D mockup.
